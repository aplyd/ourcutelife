# Project: Our Cute Life

## Purpose

Our Cute Life is an iOS-only Expo couples app that helps a couple turn small daily reflections into connection, private desire/plan matching, dates, and shared memory without making either partner feel exposed before mutual buy-in.

## Stack

- Expo SDK 56 + Expo Router
- HeroUI Native + Uniwind
- Convex backend
- Apple Authentication / Convex auth handoff
- Expo Updates / Notifications / Splash Screen / Vision Camera plugins
- pnpm, oxfmt, oxlint, TypeScript

## Product spine

Tabs/jobs:

- Today — daily ritual, relationship snapshot, recent moments
- Chat — couple + explicitly invoked AI coach conversation space
- Plans — private plan/desire matching, date recommendations, match history
- Me — profile, relationship settings, account controls
